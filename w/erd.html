// ERD & Database Design Tools

Tools that output SQL or can be converted to .sql — GUI modelers, diagram-as-code, and admin tools with ERD support
■ GUI / Visual Modelers
ToolFirstSQL OutputTagsNotes
ERwin Data Modeler ~1993 DDL forward-eng to all major DBs paid Enterprise standard. IDEF1X/IE notation. Now owned by Quest. 30+ year history.
Oracle SQL Data Modeler ~2009 DDL for Oracle, SQL Server, DB2+ free Free standalone or integrated into SQL Developer. Logical/physical/relational.
IBM InfoSphere Data Architect ~2007 DDL for DB2, Oracle, SQL Server+ paid Eclipse-based. Successor to Rational Data Architect. Enterprise data modeling.
Embarcadero ER/Studio ~1998 DDL for all major DBs paid Enterprise. Logical/physical modeling. Team collaboration features.
Sparx Enterprise Architect 2000 DDL for major DBs via data model profiles paid UML-focused but has strong ERD/DDL generation. Broad modeling tool.
FabForce DBDesigner 4 2001 DDL for MySQL, Oracle, MSSQL, ODBC GPLdefunct Delphi-based. Spiritual predecessor to MySQL Workbench. Last release 4.0.5.6.
MySQL Workbench 2005 DDL for MySQL/MariaDB freeOSS Official MySQL GUI. Successor to DBDesigner 4. Visual EER diagrams + forward/reverse eng.
Navicat Data Modeler ~2012 DDL for MySQL, PG, SQLite, SQL Server, Oracle paid Cross-platform visual modeler. Conceptual/logical/physical. Separate from Navicat DB client.
DbSchema ~2012 DDL for any JDBC-compatible DB freemium Java-based. Interactive ERD, schema sync, visual query builder. Git integration.
Vertabelo 2013 DDL for PG, MySQL, MSSQL, Oracle, SQLite+ webfreemium Browser-based collaborative data modeler. Team features. Auto-generate SQL.
SqlDBM ~2017 DDL for SQL Server, MySQL, PG, Snowflake, BigQuery, Redshift webfreemium Cloud-native database modeler. Forward/reverse eng. Team collaboration.
DrawDB 2024 DDL for MySQL, PG, SQLite, MSSQL, MariaDB webOSS Browser-based, no account needed. Visual editor exports SQL. Fast-growing OSS project.
■ Database-as-Code / DSL
ToolFirstSQL OutputTagsNotes
DBML / dbdiagram.io 2018 dbml2sql → PG, MySQL, MSSQL, Oracle OSSwebCLI Database Markup Language. CLI + web visualizer. Bi-directional SQL↔DBML. Also dbdocs.io for docs.
Prisma (schema.prisma) 2019 Migrations generate SQL for PG, MySQL, SQLite, MSSQL, CockroachDB OSSCLI Node.js ORM with declarative schema. prisma migrate produces .sql files. prisma db pull for introspection.
Atlas (by Ariga) 2021 DDL for PG, MySQL, SQLite, MSSQL, CockroachDB+ OSSCLI HCL-based schema DSL. Declarative migrations, schema diff, ERD visualizer. Go-based.
Schemacrawler ~2007 Reverse-eng DDL + ERD diagrams from any JDBC DB OSSCLI Java CLI. Generates ERD diagrams (via GraphViz) and SQL DDL from existing databases.
SchemaHero 2019 Declarative YAML → SQL for PG, MySQL, SQLite, CockroachDB OSSCLI Kubernetes-native database schema management. YAML schema definitions.
Drizzle ORM (drizzle-kit) 2022 Migrations → SQL for PG, MySQL, SQLite OSSCLI TypeScript schema definitions. drizzle-kit generate outputs .sql migration files. Drizzle Studio for visual browsing.
SqlFluff + dbt 2019 / 2016 SQL-native (schema defined in .sql models) OSSCLI dbt models define schema as SQL. SqlFluff lints. Not ERD per se but schema-as-code for analytics.
Liquibase 2006 Changelogs → SQL for all major DBs OSSCLI XML/YAML/JSON/SQL changelogs. Database migration tool, not ERD, but defines schema as code.
Flyway 2010 .sql migration files directly OSSCLI SQL-first migration tool. Version-controlled .sql files. Now owned by Redgate.
■ Diagram-as-Code (text → ERD → convertible to SQL)
ToolFirstSQL OutputTagsNotes
Mermaid.js (erDiagram) 2014 No native SQL. Convertible via LLMs, mermerd (reverse), or manual mapping. OSS Text-based diagramming. erDiagram syntax supported since ~v8. GitHub-native rendering. Huge ecosystem.
PlantUML (IE notation) 2009 No native SQL. Text-based ERD notation; convertible manually or via tooling. OSS Java-based. IE diagram support. Widely used in docs. Renders via GraphViz.
D2 (Terrastruct) 2022 No native SQL. Declarative diagramming DSL; sql_table shape type for ERDs. OSS Modern diagram-as-code. sql_table keyword for ERD shapes. No SQL export but structured text.
Structurizr (DSL) 2016 No native SQL. Architecture-as-code, can model data relationships. OSS C4 model focused. Not ERD-specific but can represent data stores in architecture.
ERAlchemy ~2015 Reverse-eng: reads SQLAlchemy/DB → generates ERD (GraphViz/Mermaid) OSSCLI Python. Generates ERD from existing databases or SQLAlchemy models.
mermerd 2022 Reverse: DB → Mermaid erDiagram syntax OSSCLI Go CLI. Connects to live DB and generates Mermaid ERD. PG, MySQL, MSSQL, SQLite.
■ DB Admin / Client Tools with ERD Features
ToolFirstSQL OutputTagsNotes
pgAdmin 1998 DDL generation for PostgreSQL OSS PostgreSQL's official admin tool. ERD designer added in pgAdmin 4. Four complete rewrites since 1998.
SQL Server Management Studio 2005 DDL for SQL Server free Database diagrams feature. Script tables/schemas as CREATE statements. Windows only.
DBeaver 2010 DDL generation for any JDBC DB OSSEE paid Universal DB client. ERD viewer in CE (auto-generated from schema). ERD editor in Enterprise.
DbGate ~2020 DDL for PG, MySQL, MSSQL, SQLite, MongoDB OSS Cross-platform DB manager. ER diagram viewer. Schema compare. Lightweight Electron app.
DataGrip (JetBrains) 2015 DDL for all major DBs paid IDE for databases. Auto-generated ERD from schema. Script generation. Refactoring support.
Toad Data Modeler ~2004 DDL for Oracle, MySQL, PG, MSSQL, DB2+ paid Part of Toad family (Quest). Physical/logical modeling. Originally Case Studio before acquisition.
HeidiSQL 2006 DDL export for MySQL, PG, MSSQL, SQLite OSS Windows MySQL/PG client. No visual ERD but exports full DDL. Lightweight and fast.
phpMyAdmin 1998 DDL for MySQL/MariaDB OSSweb Web-based MySQL admin. Designer tab for visual ERD. Export as SQL. Ubiquitous on shared hosting.
Adminer 2007 DDL for MySQL, PG, SQLite, MSSQL, Oracle OSSweb Single PHP file. Lightweight phpMyAdmin alternative. Basic schema export. No visual ERD.
Azure Data Studio 2018 DDL for SQL Server, PG OSS VS Code-based. No native ERD but has schema visualization extensions. Script generation.
DbVisualizer 2002 DDL for any JDBC DB freemium Java-based universal DB client. References/relationships viewer. DDL export.
